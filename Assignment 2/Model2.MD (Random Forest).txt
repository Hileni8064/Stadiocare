# Model 2: Random Forest

## Details
- Technique: Random Forest Classifier
- Hyperparameters:
  - n_estimators = 200
  - max_depth = None
  - min_samples_split = 2
  - random_state = 42

## Why Random Forest?
- Handles non-linear relationships
- Robust to outliers and feature scaling
- Provides feature importance ranking

## Notebook
- File: `notebooks/model2_random_forest.ipynb`
- Usage: Run after preprocessing and feature engineering. Outputs accuracy, precision, recall, F1-score, confusion matrix, feature importance.
